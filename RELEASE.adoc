= Release Process
:toc: macro
:toclevels: 2

This document describes how to create a new release of the Smartmii plugin.

toc::[]

== Overview

Releases are automated via GitHub Actions. Pushing a version tag triggers a workflow that builds the plugin ZIP, creates a GitHub Release, and updates the auto-update config files.

== Steps

=== 1. Bump the version in `plugin.cfg`

Edit `plugin.cfg` and update the `VERSION` field:

----
[PLUGIN]
VERSION=1.0.3
----

=== 2. Commit and push

----
git add plugin.cfg
git commit -m "Bump version to 1.0.3"
git push origin main
----

=== 3. Tag and push the tag

The tag must match the format `v<VERSION>` (e.g. `v1.0.3`):

----
git tag v1.0.3
git push origin v1.0.3
----

=== 4. GitHub Actions takes over

The workflow (`.github/workflows/release.yml`) runs automatically on any `v*` tag push and does the following:

. Checks out `main` with full history
. Verifies that `plugin.cfg VERSION` matches the tag (fails if they don't match)
. Builds `smartmii-v1.0.3.zip` excluding `.git/`, `.github/`, `.gitignore`, `UPDATES.md`, and `bin/__pycache__/`
. Updates `release.cfg` and `prerelease.cfg` with the new version and download URL, commits, and pushes to `main`
. Creates a GitHub Release with auto-generated release notes and attaches the ZIP

== Files involved

`plugin.cfg`::
Source of truth for the plugin version. The GitHub Actions workflow verifies the tag matches this value.

`.github/workflows/release.yml`::
The release automation workflow.

`release.cfg` / `prerelease.cfg`::
LoxBerry auto-update configuration. Updated automatically by the release workflow -- do not edit manually.

== LoxBerry Auto-Update

LoxBerry reads `release.cfg` (or `prerelease.cfg`) from the URLs configured in `plugin.cfg` under `[AUTOUPDATE]`. When a new version is available, LoxBerry shows an update notification in Plugin Management.

The `release.cfg` format:

----
[AUTOUPDATE]
VERSION=1.0.3
ARCHIVEURL=https://github.com/wkulhanek/loxone-smartmii/releases/download/v1.0.3/smartmii-v1.0.3.zip
INFOURL=https://github.com/wkulhanek/loxone-smartmii/releases
----

== Upgrade Safety

The plugin preserves user configuration across upgrades:

. `preupgrade.sh` backs up the config directory (`LBPCONFIGDIR`) to `/tmp/` before the upgrade
. LoxBerry replaces all plugin files with the new version
. `postinstall.sh` restores the backed-up config into the new installation
. Fresh installs (no backup found) get a default empty config

This ensures fan registrations and cloud sessions survive plugin updates.
